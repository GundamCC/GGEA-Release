### v1.1.9.0 — 正式发布 / Release

### v1.1.8.2 — 正式发布 / Release

修复历史 BOSS 战后返回列表缺少专用确认的问题：结算或剧情结束后，复用本作品的标题与 Logo 识别，并检查同帧可读 BOSS 卡片，确认返回后交回队列继续复核通关状态。标题残帧、卡片未加载和其他作品不能通过新增确认；保留原有通用返回路径、超时与安全保护。

### v1.1.8.1 — 正式发布 / Release

修复自动推图略过后停在故事首次观看报酬弹窗的问题：每次 SKIP 后在底部按钮区域核对 OK 文字及完整按钮并点击，再以新截图确认返回选择关卡；观看关卡的执行确认和十五秒循环继续保留。两分钟静止巡查增加同一 OK 识别，可恢复未记录本次略过的奖励弹窗。重复弹窗有限点击且不会刷新静止计时，保留失败、AP、网络与取消保护。使用 MuMu 5556 当前奖励原帧回归。

### v1.1.8.0 — 正式发布 / Release

自动推图为观看关卡增加十五秒循环：首次执行后等待十五秒点击画面中央，再从新截图识别右上角 SKIP 并确认底部执行按钮；略过后持续检查选择关卡、出击准备等返回入口，未确认返回则等待下一轮继续。执行确认暂未出现时结束本轮观察并重试，不因单轮漏识别直接停止；保留总超时、卡顿、取消、网络、失败与 AP 安全保护，普通出击流程不变。

### v1.1.7.2 — 正式发布 / Release

### v1.1.7.0 — 正式发布 / Release
