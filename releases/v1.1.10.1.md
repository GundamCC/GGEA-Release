新增 GitHub 在线更新：启动后后台检查正式版本，有新版时在任务空闲后弹窗展示更新内容，可下载并校验完整包，确认后由独立更新器重启安装；也可选择稍后处理或在设置页手动检查，不强制更新。保留用户配置、AP 方案、已采集坐标和未知文件；安装失败恢复旧版，中断后启动提供恢复入口。第一版仅使用 GundamCC/GGEA-Release，不支持增量更新或其他下载源；开发及本地构建版本仅支持检查。

### v1.1.9.1 — 正式发布 / Release

修复每日 AP 略过导航到作品 ID 1 时在地图边界重复右滑直至超时的问题：预测目标已进入画面时等待识别，滑动后无明显位移时停止重复手势并有限恢复；保留目标未识别的同帧截图及目标候选分数。预测坐标不授权点击，识别阈值、连续帧确认与 AP 安全校验保持不变。

请下载本页 Assets 中的 ZIP 与同名 .zip.sha256；完整解压后运行 GGEA.exe。请勿将 GitHub 自动生成的 Source code 压缩包当作程序。SHA-256 只用于完整性校验，不是数字签名。

发布包通过现有构建、测试、解压、文件摘要与 EXE 自检，并已由维护者完成设备、截图及单项低风险流程的人工验收。
