## 更新内容

GGEA v0.9.7.3 — 正式发布 / Release

修复 MuMu（含国际版）多标签页下任务开始后输入落入安卓桌面的问题：配置 MuMuManager.exe 后，每次点击、滑动或按键前按所选设备和 gamePackage 确认游戏正在运行的显示屏，并通过 input -d 显式投递。不缓存显示编号；游戏未打开、显示归属不唯一或查询失败时停止输入，不回退桌面。关闭原生截图仍保留输入保护；原始双指事件无法指定独立显示屏时明确停止。日志记录设备、游戏包名和输入显示编号，便于与原生截图日志核对。

修复 MuMu 多显示/截图增强环境下普通 ADB 可能取错游戏画面的问题：配置 MuMuManager.exe 后默认使用模拟器自带的 external_renderer_ipc.dll 原生截图，按管理器在线实例及 boot_id 确认设备，按 gamePackage 选择游戏显示，并转换倒序 RGBA 为正序 BGRA。首次日志显示 MuMuNative、实例与显示编号。SDK 调用隔离在限时子进程，失败明确停止而不静默回退。请先在所选实例打开目标游戏；需要支持 nemu_get_display_id 的 MuMu 版本。本程序不附带或下载厂商 DLL，不改动 MAA 设置。高级兼容选项 preferMuMuNativeScreenshot=false 可显式恢复 ADB 截图；其他模拟器仍使用原有 ADB 截图和输入。

新增主界面识别失败证据包：主界面两种按钮状态或返回按钮未命中时，在 logs/recognition 保存参与本次识别的原始 PNG、实际模板和 diagnostic.json（阈值、搜索区域、算法最佳候选分数与位置）。不降低业务阈值、不额外截图、不自动上传；同设备同类失败一分钟一次，每进程最多轮转保留五包。日志提示 ZIP 路径，复现后请检查画面中的隐私信息，再将对应 ZIP 与普通日志一并反馈。

修复 ADB 截图 PNG 前混入额外输出时被拒绝的问题：在前 4096 字节内识别 PNG 签名，仅在块结构、CRC、结束块与实际像素解码均通过后移除前缀；首次恢复记录长度，不记录原文。损坏、截断、异常尺寸或尾部污染仍拒绝使用。

修复 ADB 中文输出乱码：文本标准输出和错误输出优先按严格 UTF-8 解码，旧版工具回退 Windows ANSI 代码页；截图二进制保持原样。已写入旧日志的乱码不自动修复，连接拒绝（10061）仍需检查目标实例与端口。

每日任务恢复主界面时，主界面按钮未命中会直接检查底部关闭按钮；每次关闭后重新识别主界面，仍未命中则继续检查关闭按钮。关闭按钮未命中时保持静默，再检查返回按钮；恢复循环有超时上限。
