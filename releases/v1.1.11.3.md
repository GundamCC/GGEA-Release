## 更新内容（自 v1.1.10.1 以来）

### v1.1.11.3 — 正式发布 / Release

修复消耗 AP 作品导航被连续 TAP TO NEXT 弹层阻塞的问题：继续提示优先于背景 Logo、选择按钮与滑动；每次命中重新开始识别时间，不限制连续弹层的累计处理时长和数量。最后一次命中后持续观察五秒，无新提示才恢复导航；保留点击冷却、用户取消与网络安全检查。

### v1.1.11.2 — 正式发布 / Release

移除面向用户的备用源导入按钮、文件选择与相关提示。备用更新源统一由维护者配置，当前列表保持为空，后续提供服务器时再接入；保留 GitHub 优先、已配置来源缓存与连接失败自动切换。

### v1.1.11.1 — 正式发布 / Release

缩减独立更新器体积：仅裁剪更新进程未使用的运行库，并为交接请求、恢复记录使用编译期 JSON 元数据；继续支持无需安装 .NET 的独立运行、旧版记录恢复、用户配置保留与失败回滚。在线更新仍下载完整包。

### v1.1.11.0 — 正式发布 / Release

新增可缓存的备用更新源：GitHub 优先，连接失败时尝试远程配置缓存或手动导入的备用源；下载失败仅切换同版本、同大小且已知摘要一致的完整包。更新界面支持导入维护者提供的来源配置并显示当前来源。备用地址初始为空，后续通过公开发布仓库的固定配置文件下发；没有缓存且 GitHub 完全不可访问时需手动导入。保持 HTTPS 域名限制、SHA-256、包内清单和安装恢复校验，不强制更新。

请下载本页 Assets 中的 ZIP 与同名 .zip.sha256；完整解压后运行 GGEA.exe。请勿将 GitHub 自动生成的 Source code 压缩包当作程序。SHA-256 只用于完整性校验，不是数字签名。

发布包通过现有构建、测试、解压、文件摘要与 EXE 自检，并已由维护者完成设备、截图及单项低风险流程的人工验收。
