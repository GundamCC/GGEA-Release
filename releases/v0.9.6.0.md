## 更新内容

GGEA v0.9.6.0 — 正式发布 / Release

新增独立环境日志 logs/environment-日期-进程号.log：启动及截图失败时记录本机系统、内存、权限、磁盘与工具信息，普通错误日志通过 environmentId 关联。反馈时请同时提供对应普通日志和环境日志（及存在时的 .previous 文件）。仅本地保存，不采集环境变量、完整命令行或截图；标准用户目录脱敏。相同设备同阶段故障一分钟内复用快照，每文件达到 1 MiB 后保留一份轮转副本。环境日志不主动调用 ADB，未采集 Android 内部状态，不能据此排除设备端故障。

截图失败诊断增加实际设备、ADB 路径、命令、阶段与耗时；校验完整 PNG 签名并区分空输出、前置输出及疑似换行转换，不记录原始截图内容。未知格式仍需进一步采样，不能仅凭本次改动认定兼容性故障已修复。

新增首次启动 ADB 检索与路径历史下拉列表。单候选自动选中，多候选优先使用可读取执行记录中最近运行的 ADB；无法判断时提示用户确认，检索失败时引导手动浏览并保存。

PNG 编解码复用进程级 STA 线程，避免持续创建线程与 WPF 隐藏窗口；补充并发、线程复用及异常后恢复验证。

修复自动刷本失败及 AP 不足时仍继续执行的问题，并同步发布文档版本，确保正式打包校验通过。

修复 PNG 编解码线程的 WPF 资源释放，统一 BGRA 像素格式；发布自检同时验证原生库与实际模板解码路径。

本版统一源码提交、程序版本、默认资源/配置及 ZIP 身份，修复旧程序混用新说明或配置的打包风险。
build-info.json 记录完整 Git 提交、Release/win-x64 构建参数、SDK、资源/配置内容版本、Billing 版本及逐文件 SHA-256。
ZIP 文件名含版本与提交前 12 位，旁边的 .sha256 用于核验下载完整性（不等同于数字签名）。

自动验收：Release Build、dotnet test、资源引用校验、Billing 摘要、打包防混用回归；从实际 ZIP 解压后检查完整清单并启动 GGEA.exe --verify-release，加载原生图像库、解码 PNG 与检查 JSON/Billing 组件。
自动自检不操作模拟器；每次公开发布前另需从解压验收目录完成设备、截图和单项低风险流程的人工验证。

首次使用须有人看护。不承诺无人值守，也不承诺未验证的模拟器、Android/游戏版本、语言或分辨率兼容。
请在 ZIP 解压目录按使用说明完成设置、截图/设备检查与单项低风险流程验证，再逐步启用其它任务；出现错位、识别失败或意外弹窗应立即停止。
业务自动化要求 1920×1080 横屏；Billing 可选功能仅适用于开启 Root 的 x86_64 Android 模拟器。
完整包为 Windows win-x64 自包含程序。终端用户不需要安装 .NET SDK、Python、NDK、JDK 或 Frida。
