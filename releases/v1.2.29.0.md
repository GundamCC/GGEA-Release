## 更新内容（自 v1.2.17.0 以来）

### v1.2.29.0 — 正式发布 / Release

大师联盟入口中心点击上限调整为十五次，每次点击后等待 1.2 秒；第十次后检查标题，第十一至十五次逐次截图查找，标题出现立即停止补点。

### v1.2.28.2 — 正式发布 / Release

修复大师联盟迟到晋级提示卡住：选敌或准备阶段也接管 TAP TO NEXT，晋级后重新读取新一轮列表；新增按单调时间触发的两分钟无进展恢复检查，重新识别当前弹层、结算、继续提示与导航页，并明确记录检查结果，不重发挑战或刷新消费。

### v1.2.28.1 — 正式发布 / Release

修复大师联盟进入选敌页时被“关卡情报＆增幅信息”弹层阻塞：同帧确认选敌页与信息标题后点击关闭，弹层残留期间不重复点击、不读取背景对手；消失后重新确认列表并继续按 32415 选敌。

### v1.2.28.0 — 正式发布 / Release

大师联盟入口中心点击上限调整为十二次：前十次保持每次间隔一秒，第十次后开始逐次识别标题；第十一、十二次点击后均重新截图确认，标题出现立即停止补点。

### v1.2.27.1 — 正式发布 / Release

修复大师联盟“挑战模式已解放”提示停滞：继续文字识别覆盖底部 300 像素，支持位置较高的 TAP TO NEXT；优先处理提示后再读取对手列表，保留原识别阈值与三页继续上限。

### v1.2.27.0 — 正式发布 / Release

大师联盟不再读取或判断总积分、期间最高积分及晋级门槛，也不再按十五万分自动停止。挑战按第 3、2、4、1、5 名顺序，根据对手零分与胜负状态推进，晋级提示后确认新一轮零分列表并重置挑战记录；保留持续恢复与取消。

### v1.2.26.1 — 正式发布 / Release

修复 MuMu 设备刷新漏检：管理器返回空列表时继续尝试另一种查询参数；管理器只识别部分实例时仍补查本机实际监听端口；已在线实例不再占用补查名额。保留手动选择设备、实例身份校验和独立显示屏截图安全保护。

### v1.2.26.0 — 正式发布 / Release

大师联盟改为持续运行与阶段恢复：识别失败、设备断连和加载超时进入低频重试，保留已发送挑战、刷新和继续页计数，不因局部异常结束任务；未知单列信息不阻塞其他明确零分目标。入口会重试，运行中可随时中止，目标完成、次数耗尽或没有授权操作时结束。

### v1.2.25.4 — 正式发布 / Release

调整大师联盟选敌判定：明确显示胜利或败北的对手不再要求读取具体积分，也不因该分数 OCR 波动阻塞下一场；未挑战目标仍须确认零分，刷新后仍须确认积分清零。

### v1.2.25.3 — 正式发布 / Release

修复大师联盟积分千位分隔空隙导致 OCR 置信度不足的问题。数字识别失败时保留字形并统一间距复核，保持原置信度门槛且要求两次数字一致；返回超时日志区分页面未出现与页面数据未读全。

### v1.2.25.2 — 正式发布 / Release

修复大师联盟结算返回时漏掉延迟出现的晋级与报酬页面。持续检测 TAP TO NEXT 和对手页，最多继续三页；主流程连续确认完整对手信息后才开始下一场。

### v1.2.25.1 — 正式发布 / Release

修复大师联盟点击挑战后未处理游戏数据下载弹窗的问题。复用下载许可设置，允许时只确认一次并继续检测战斗与结算；未允许时取消并停止，避免停留在下载弹窗。

### v1.2.25.0 — 正式发布 / Release

大师联盟接通自动编制、零积分选敌、挑战、SKIP 与结算并行识别、返回及晋级继续的完整流程。可选在五人均已挑战且积分不足时刷新败北对手，目标对手积分归零即确认刷新成功；结算使用固定区域 BATTLE SCORE OCR，返回后最多处理三页 TAP TO NEXT。支持积分与次数识别、取消及有界等待，达到大师联盟 150000 积分目标后停止；PvP 素材统一归入 stage/pvp。

### v1.2.24.0 — 正式发布 / Release

采集简中对手选择页标题、胜利/败北标记与对战按钮；新增五个敌人战斗评价、胜负标记及可变更剩余次数的识别区域布局。本次仅准备素材与区域，尚未接入评价和次数 OCR 或自动对战。

### v1.2.23.0 — 正式发布 / Release

大师联盟支持编制空位提示：识别提示文字与对话框内“确定编制”后确认一次，重新识别大师联盟标题和“选择对战对手”按钮，再点击进入对手选择；无空位时直接返回并继续，未勾选自动编制时直接选择对手。保留取消、超时及同帧识别保护，不自动开始战斗。

### v1.2.22.0 — 正式发布 / Release

大师联盟自动编制复用自动推图的自动编制按钮、弹窗标题与确定按钮识别流程；编制后识别并点击“确定编制”，确认返回大师联盟界面后结束，不自动选择对战对手。保持默认关闭、简中游戏界面限制及取消保护。

### v1.2.21.0 — 正式发布 / Release

新增“大师联盟”页签，位于强敌来袭右侧，支持从关卡进入并识别标题；标题未命中时中心点击十次、每次间隔一秒后复查，失败即停止。提供默认关闭的“进行自动编制”选项，勾选后进入并确认对战编制页；采集对战编制标题及确定编制按钮，当前不执行自动选队或确认编制，仅支持简中游戏界面。

### v1.2.20.0 — 正式发布 / Release

新增简体中文大师联盟“编制”和“选择对战对手”按钮模板，记录裁剪区域及中心坐标；本次仅采集素材，尚未接入按钮点击及 PvP 自动流程。

### v1.2.19.0 — 正式发布 / Release

新增从 MuMu 实际画面采集的简体中文大师联盟标题模板，记录关卡页入口坐标及标题识别区域；本次仅准备素材，尚未接入 PvP 自动流程。
